## Contratto HTTP e OpenAPI

Il contratto osservato resta documentato in `docs/API.md`. Non è stato generato uno snapshot OpenAPI: `Program.Main`
chiama `Settings.Load()`, inizializza il context, esegue `EnsureCreated()` e il seed prima di costruire l'host ASP.NET.
Generare Swagger avviando il processo potrebbe quindi creare o modificare un database non posseduto dal run. TST-02
è responsabile di rendere l'host testabile e di produrre la baseline OpenAPI senza usare una destinazione condivisa.

## Versione MySQL

Il repository non include MySQL in Compose e `settings.example.json` non dichiara una versione server. La versione
effettivamente usata dal sistema legacy non è quindi verificabile senza accedere a un ambiente esterno.

Punto aperto `BSL-DB-01`: il proprietario dell'ambiente deve registrare la versione del server legacy prima di DB-21;
TST-01 userà invece la linea MySQL 8.4 LTS approvata da DEC-07 per l'ambiente effimero di test.
