## Baseline e modifiche

- Rebuild Release iniziale: 41 warning, 0 errori. Il valore storico di 79 warning nel piano precedeva gli interventi delle fasi precedenti.
- Entità EF: stringhe obbligatorie e collection inizializzate; navigation dichiarate nullable quando possono non essere caricate. Nei mapper in memoria, assenza di una relazione richiesta produce un errore esplicito; nelle query EF, `!` è limitato alle relazioni con FK obbligatoria tradotte in join SQL.
- DTO e modelli legacy inizializzati senza cambiare il contratto OpenAPI. PBKDF2 usa l'API statica SHA-256, mantenendo formato, salt e iterazioni. Un vettore generato con il vecchio costruttore verifica la compatibilità degli hash già salvati.
- Rimossi otto costruttori serialization formatter obsoleti, `WeatherForecast`, `ExportManager` inutilizzato e launch profile CLI con path personale. Il `UserManager` custom non era più nel repository: restano solo i consumer di ASP.NET Identity.
- Corretti i nomi interni `MoneyManagerController`, `TokenExpiredException`, `UserPermissionException`, `GREATER` e `Descending`; mapping HTTP ed error code invariati. `webserver.http` usa gli health endpoint. Snapshot legacy aggiornato soltanto per la rimozione del template; snapshot v1 invariato.
- Corretti i simboli naming di `.editorconfig`, rimossi using accidentali verso il namespace transitivo BouncyCastle e normalizzati gli import con `dotnet format style` e attivato `TreatWarningsAsErrors` per tutta la soluzione tramite `backend/Directory.Build.props`. Nessuna soppressione globale.
