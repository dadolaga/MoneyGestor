# Evidenza SEC-10 — 22 settembre 2026

## Esito

SEC-10 è completato. Il contratto HTTP non cambia.

- `EnableSensitiveDataLogging()` e `EnableDetailedErrors()` sono stati rimossi.
- Il logging EF è disabilitato per default e in ogni ambiente Production; `Development + Trace` abilita soltanto gli
  eventi SQL senza valori dei parametri.
- Le eccezioni di autenticazione non includono più il token.
- I log delle risposte contengono status, codice applicativo, route e trace ID, senza message o data.
- Il request logging contiene metodo, route, status, durata e trace ID, senza header `Authorization` o body.
- Gli errori import registrano operazione e tipo di eccezione senza il messaggio derivato dall'input.
- I sink file applicano rolling giornaliero e retention massima di 14 file.

## Policy TRACE

TRACE aumenta il dettaglio diagnostico ma non è un bypass della redazione. Password, token, header, body, payload di
risposta e valori dei parametri SQL restano esclusi. Questo evita che un'attivazione temporanea durante un incidente
trasformi file locali o sistemi centralizzati di log in archivi di credenziali.
